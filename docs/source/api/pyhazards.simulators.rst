pyhazards.simulators package
============================

Adapters to external, physics-based fire simulators. ForeFire runs through
:class:`~pyhazards.simulators.ForeFireSimulator` (the official ``pyforefire``, installed
separately); WRF-SFIRE outputs are read by :mod:`pyhazards.datasets.wrf_sfire`. See
:doc:`/pyhazards_simulators`.
