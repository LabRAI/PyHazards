Description
-----------

``utae`` encodes every date of a satellite image time series with a shared convolutional encoder, collapses time at the lowest resolution with a Lightweight Temporal Attention Encoder (L-TAE), reuses the attention masks to aggregate the skip connections, and decodes to per-pixel scores (Sainte Fare Garnot & Landrieu, ICCV 2021).

The implementation is a port of the official utae-paps code, which WildfireSpreadTS vendors unchanged. Parameter names match the reference, so the official PASTIS checkpoints load with ``strict=True``. Acquisition dates go in ``batch_positions`` (day of year in WildfireSpreadTS); when omitted, ``0..T-1`` is used.

Programmatic Use

   import torch
   from pyhazards.models import build_model

   model = build_model(name="utae", task="segmentation", in_channels=40)
   x = torch.randn(2, 5, 40, 128, 128)
   day_of_year = torch.tensor([[150, 151, 152, 153, 154]] * 2, dtype=torch.float32)

Notes
-----

- Height and width must be divisible by 8 with the default three down-sampling stages.
- As in the reference code, the output block ends with BatchNorm and ReLU, so scores are non-negative.
- Dates whose frame equals pad_value (default 0) everywhere are treated as padding.
