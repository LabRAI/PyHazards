Description
-----------

``segformer`` encodes the input with a four-stage Mix Transformer (MiT): overlapping patch embeddings, efficient self-attention whose keys and values are spatially reduced, and Mix-FFN layers whose depth-wise convolution replaces positional encodings, so any input size works. An all-MLP head projects the four stages to a common width, upsamples them to 1/4 resolution, fuses them and predicts per-pixel logits (Xie et al., NeurIPS 2021).

The network is a plain-PyTorch port of Hugging Face transformers' SegFormer (4.57.6) with the same module names, initialisation and outputs: ``SegformerForSemanticSegmentation`` state dicts and the ``nvidia/mit-b*`` ImageNet encoders load with ``strict=True``. ``variant`` selects MiT-B0 to B5 (decoder width 256 for B0/B1, 768 for B2-B5). The logits are resized to the input size by default; ``raw_logits()`` returns the 1/4-resolution decoder output.

Used In
-------

- `Improved Wildfire Spread Prediction with Time-Series Data and the WSTS+ Benchmark <https://arxiv.org/abs/2502.12003>`_: Lahrichi, Bova, Johnson & Malof, WACV 2026. SegFormer-B2 trained on 128x128 WildfireSpreadTS crops without padding, encoder initialised from nvidia/mit-b2 (ImageNet-1k), decoder from scratch, focal loss (alpha = inverse positive-pixel frequency, gamma = 2), AdamW, batch 64, 10k iterations, learning rate from a grid search on one fold. One day (Veg 7, Multi 33, All 40 channels) or five days concatenated on channels with the WildfireSpreadTS layout (static features only on the last day; 120 channels for All). Reported 27.5M (T=1) and 27.7M (T=5) parameters, matching B2 with 40 and 120 input channels (27,463,425 and 27,714,305). Mean test AP over 12 folds 0.433 / 0.436 / 0.423 (T=1, Veg / Multi / All) and 0.439 / 0.436 / 0.430 (T=5), below the paper's ResNet-18 U-Net. The paper does not say how the 3-channel mit-b2 patch embedding was adapted to the wildfire channels.

Reproduction
------------

- **Reference implementation:** `https://github.com/huggingface/transformers/blob/v4.57.6/src/transformers/models/segformer/modeling_segformer.py <https://github.com/huggingface/transformers/blob/v4.57.6/src/transformers/models/segformer/modeling_segformer.py>`__ at ``v4.57.6`` (Apache-2.0)
- **Checked configuration:** SegformerForSemanticSegmentation with the MiT-B0 (3 channels, 150 classes) and MiT-B2 (40 channels, 1 class, the WSTS+ setting) configurations of nvidia/mit-b*, SegformerModel (B0, 5 channels), and the revision-pinned Hub checkpoints nvidia/mit-b0 (ImageNet-1k encoder, also adapted to 1/7/40 channels and compared with smp 0.3.2 patch_first_conv) and nvidia/segformer-b0-finetuned-ade-512-512 (ADE20K, compared with transformers' post_process_semantic_segmentation).
- **Parameter count:** 27,463,425
- **Verified:** parameter count, seeded initialisation, parameter names and shapes, forward outputs, official pretrained weights
- **Oracle test:** ``tests/oracle/test_segformer_oracle.py``
- **Deviation:** forward() resizes the logits from 1/4 resolution to the input size (bilinear, align_corners=False), as transformers' post-processing and loss and mmseg's inference do outside the network; SegformerForSemanticSegmentation itself returns the 1/4-resolution logits, available here from raw_logits() or with upsample=False.
- **Deviation:** With encoder_weights and in_channels other than 3, the first patch embedding is adapted the way segmentation_models_pytorch adapts ImageNet encoders (RGB filters repeated over the channels and scaled by 3 / in_channels; summed for one channel). transformers' from_pretrained(..., ignore_mismatched_sizes=True) would re-initialise it instead; WSTS+ does not say which it did.
- **Deviation:** Only logits are returned: no loss from labels, attention maps or output dataclasses (SegformerModel returns the four stage outputs as a list). transformers' deprecated reshape_last_stage=False and head pruning are not supported.

Programmatic Use

.. code-block:: python

   import torch
   from pyhazards.models import build_model

   # SegFormer-B2 as in WSTS+: 40 channels (one day, all features), one output.
   model = build_model(name="segformer", task="segmentation", in_channels=40)
   logits = model(torch.randn(2, 40, 128, 128))

   # ImageNet-1k MiT-B2 encoder (non-commercial NVIDIA weights, downloaded on request).
   pretrained = build_model(name="segformer", task="segmentation", in_channels=40, encoder_weights="imagenet")

Notes
-----

- NVIDIA licenses the SegFormer and MiT weights (nvidia/mit-b*, nvidia/segformer-*) for non-commercial use only (NVIDIA Source Code License for SegFormer). PyHazards does not bundle them; encoder_weights="imagenet" downloads the revision-pinned nvidia/mit-<variant> checkpoint from the Hugging Face Hub, and a local pytorch_model.bin or model.safetensors path also works.

- load_hf_state_dict() loads transformers state dicts: SegformerForSemanticSegmentation into the whole model; SegformerForImageClassification (nvidia/mit-b*: the "segformer." prefix is removed and the ImageNet classifier dropped) and SegformerModel into model.segformer.

- Like transformers, every LayerNorm uses eps=1e-5. The official MiT uses 1e-6 in the Transformer blocks and stage norms; with the ADE20K B0 weights this changes logits by up to about 6e-3 (99.99% argmax agreement on random input).

- Mix-FFN expansion is 4 in every stage, as in the released code and checkpoints; the paper's Table 6 lists 8 for stages 1-2 of B0-B4. The decode-head dropout is element-wise as in transformers, where mmseg uses channel-wise Dropout2d; this only matters in training.

- Height and width must be at least 29; they need not be multiples of 32.
- Multi-day input (batch, time, channels, height, width) is flattened time-major to time * channels. The deduplicated WildfireSpreadTS layout (120 channels for five days of all features) is built by the data pipeline and passed as (batch, 120, height, width).
