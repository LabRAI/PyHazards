Description
-----------

``wildfirespreadts`` builds one of the learned baselines of the WildfireSpreadTS benchmark for next-day active-fire segmentation, configured exactly as in the benchmark code. ``baseline`` selects ``logistic_regression``, ``resnet18_unet``, ``convlstm`` or ``utae`` (default).

Each baseline is also available on its own (``logistic_regression``, ``resnet18_unet``, ``convlstm``, ``utae``) with configurable hyperparameters; this entry fixes them to the benchmark values. ``in_channels`` is the number of features per day (40 with all features) and ``history`` the number of days that the U-Net and logistic regression flatten into channels.

Notes
-----

- The benchmark trains on random 128x128 crops; ConvLSTM is evaluated by tiling 128x128 crops.
- For the multi-day U-Net, the 20 static features (topography, land-cover one-hot) are kept for the last day only, as in the benchmark (remove_duplicate_features): 120 input channels and 14,695,121 parameters for 5 days.
- Training losses differ per baseline: Dice (logistic regression, U-Net), Jaccard (ConvLSTM), weighted BCE (U-TAE).
