Description
-----------

``convlstm`` runs a stack of ConvLSTM cells (Shi et al., 2015) over a ``(batch, time, channels, height, width)`` sequence and maps the cell state of the last time step to per-pixel logits with a ``Conv2d`` head.

The implementation is a port of the ConvLSTM that WildfireSpreadTS vendors from utae-paps (originally TUM-LMF/MTLCC-pytorch): gates come from one convolution over the concatenated input and hidden state, there are no peephole connections, and the head reads the cell state rather than the hidden state. Parameter names match the reference, so its state dicts load with ``strict=True``.

Reproduction
------------

- **Reference implementation:** `https://github.com/VSainteuf/utae-paps <https://github.com/VSainteuf/utae-paps>`__ at ``987874e`` (MIT)
- **Checked configuration:** ConvLSTM_Seg(num_classes=1, input_dim=40, hidden_dim=64, kernel_size=(3, 3)), the WildfireSpreadTS configuration; WildfireSpreadTS vendors this file unchanged.
- **Parameter count:** 240,449
- **Verified:** parameter count, seeded initialisation, parameter names and shapes, forward outputs
- **Oracle test:** ``tests/oracle/test_wildfirespreadts_oracle.py``
- **Deviation:** The reference fixes the spatial size at construction; this port reads it from the input. Outputs are identical at the reference size.
- **Deviation:** The reference head uses ``padding=1`` for every kernel size; this port uses ``kernel_size // 2``, which only differs for kernels other than 3x3.
