TCN
===

Overview
--------

``tcn`` maps a ``(batch, time, features)`` sequence through residual blocks of two causal dilated 1D convolutions (dilation ``2 ** i`` at level ``i``), each with weight normalisation, ReLU and dropout, with a 1x1 convolution on the residual path when the width changes. The output at step ``t`` only depends on steps up to ``t``. A linear head reads the last time step (``readout="last"``, sequence classification or regression) or every step (``readout="sequence"``).

Description
-----------

``tcn`` maps a ``(batch, time, features)`` sequence through residual blocks of two causal dilated 1D convolutions (dilation ``2 ** i`` at level ``i``), each with weight normalisation, ReLU and dropout, with a 1x1 convolution on the residual path when the width changes. The output at step ``t`` only depends on steps up to ``t``. A linear head reads the last time step (``readout="last"``, sequence classification or regression) or every step (``readout="sequence"``).

The implementation is a port of ``TemporalConvNet`` / ``TemporalBlock`` / ``Chomp1d`` from the official locuslab/TCN code with the linear heads of its example tasks. Weight normalisation uses ``torch.nn.utils.parametrizations.weight_norm`` instead of the deprecated hook-based ``torch.nn.utils.weight_norm``; the computation and initialisation are identical, official state dicts load with ``strict=True``, and ``to_official_state_dict`` converts back.

No wildfire study using this network was found. The "TCN" of the WildfireIA benchmark is a different, non-causal design (see Used In) and is not what this model implements.

Used In
-------

- `A Nationwide Benchmark for Wildfire Initial Attack Failure Prediction with Public Environmental Data (WildfireIA) <https://arxiv.org/abs/2606.15529>`_ (`repo <https://github.com/LabRAI/WildfireIA>`__): Not this model. WildfireIA's TCN baseline (train.py TCNClassifier at aba9be9, MIT) has three non-causal residual blocks (kernel 3 with symmetric padding, dilations 1/2/4, 128 channels, BatchNorm instead of weight normalisation, no ReLU after the residual sum), mean-pools over the T=5 daily weather / fire-danger steps and concatenates a static-feature MLP before an MLP head. Initial-attack failure prediction on 38,128 FPA-FOD fires: AUPRC 50.4 +/- 0.3, AUROC 83.7 +/- 0.5 (Table 3); containment duration: MAE 36.1 h (Table 6).

Reproduction
------------

- **Reference implementation:** `https://github.com/locuslab/TCN <https://github.com/locuslab/TCN>`__ at ``2f8c2b8`` (MIT)
- **Checked configuration:** Adding problem TCN(2, 1, [30] * 8, kernel_size=7, dropout=0.0) (add_test.py defaults, the builder defaults here); sequential MNIST TCN(1, 10, [25] * 8, kernel_size=7, dropout=0.05) in eval and train mode (66,910 parameters); the per-step heads of copy memory (TCN(1, 10, [10] * 8, kernel_size=8)) and polyphonic music (TCN(88, 88, [150] * 4, kernel_size=5, dropout=0.25)); causality of TemporalConvNet.
- **Parameter count:** 96,001
- **Verified:** parameter count, seeded initialisation, parameter names and shapes, forward outputs
- **Oracle test:** ``tests/oracle/test_tcn_oracle.py``
- **Deviation:** Weight normalisation is ``torch.nn.utils.parametrizations.weight_norm``, so g and v are stored as ``<conv>.parametrizations.weight.original0`` / ``original1`` instead of ``weight_g`` / ``weight_v``. Official state dicts load unchanged (PyTorch renames the keys while loading) and ``to_official_state_dict`` gives the official names; outputs are identical.
- **Deviation:** ``TCN`` takes ``(batch, time, features)`` and transposes it to the official ``(batch, channels, length)``; ``TemporalConvNet`` keeps the official layout.
- **Deviation:** Heads return raw scores: the sequential-MNIST model's ``log_softmax`` and the music model's ``sigmoid`` (in float64) are left to the loss.
- **Deviation:** Kernel sizes below 2 raise ValueError at construction; in the official code ``Chomp1d(0)`` returns an empty sequence and the next convolution raises a RuntimeError.

Notes
-----

- As in the official code, init_weights draws N(0, 0.01) into the computed weights of the weight-normalised convolutions, and weight normalisation discards them: those convolutions keep PyTorch's default initialisation, and only the 1x1 residual convolutions (and the head with head_init='normal') are N(0, 0.01). The draws are kept so a seed gives the official parameters.
- Defaults reproduce the official adding-problem model (input_dim 2, 8 levels x 30 channels, kernel 7, no dropout). Paper Table 2 lists per-task settings of about 70K parameters, e.g. adding problem T=600: hidden_dim=24, num_levels=8, kernel_size=8.
- The receptive field is 1 + 2 (kernel_size - 1)(2^num_levels - 1) steps (3,061 with the defaults); short wildfire histories need far fewer levels.
- head_init='default' keeps PyTorch's Linear initialisation, as the official sequential-MNIST and music models do; readout='sequence' returns (batch, time, out_dim).
