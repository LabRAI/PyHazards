Description
-----------

The paper's EQNet is a multi-station network for joint phase picking, association and event detection: a 1-D ResNet-18 feature extractor per station, P and S picking heads that output activation sequences, and a shift-and-stack module that moves the station features by predicted travel times over a grid of candidate hypocentres before an event detector. It takes gathers of stations with their coordinates.

``eqnet`` here is unrelated to that design: a Conv1d projection, a two-layer ``nn.TransformerEncoder`` (48 dimensions, 4 heads), mean pooling and an MLP returning ``(batch, 2)`` regressed arrival samples for a single trace (41,138 parameters). It is kept only so that existing code keeps working until EQNet is rewritten from the paper; the ``earthquake.picking`` benchmark scores its two outputs as one P and one S pick per trace.

Notes
-----

- Not faithful: none of EQNet's ResNet backbone, picking heads, shift-and-stack association or multi-station input is implemented (audit of 2026-10-07).
- Zhu, Tai, Mousavi, Bailis & Beroza, J. Geophys. Res. Solid Earth 127(3), e2021JB023283 (2022), arXiv:2109.09911.
- The AI4EPS/EQNet repository (now a toolbox of PhaseNet+ / PhaseNet-DAS models) is under an academic / non-commercial licence and does not contain the paper's shift-and-stack model, so EQNet has to be rewritten from the paper; the repository may serve only as a test oracle.
- Self-attention over every sample makes long windows expensive; the smoke config uses 512-sample synthetic windows.
