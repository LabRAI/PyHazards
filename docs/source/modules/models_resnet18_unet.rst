Description
-----------

``resnet18_unet`` pairs a torchvision-style ResNet-18 encoder with the U-Net decoder of segmentation_models_pytorch: five nearest-neighbour upsampling blocks with skip connections and two Conv-BN-ReLU layers each, followed by a 3x3 segmentation head.

The network is a plain-PyTorch re-implementation of ``smp.Unet("resnet18")`` from segmentation_models_pytorch 0.3.2, the version WildfireSpreadTS pins, with the same initialisation and parameter names. ``encoder_weights="imagenet"`` loads the ImageNet ResNet-18 checkpoint and adapts the first convolution to the input channels the way smp does. Multi-day input ``(batch, time, channels, height, width)`` is flattened to ``time * channels`` channels.
