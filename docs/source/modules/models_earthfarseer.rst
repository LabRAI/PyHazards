Earthfarseer
============

Overview
--------

``earthfarseer`` maps ``T`` input frames ``(batch, T, C, H, W)`` to the next ``T`` frames (Wu et al., AAAI 2024). The spatial block FoTF runs a global Fourier transformer (16x16 patches, 12 blocks of width 768 whose token mixing is an adaptive Fourier neural operator, then three transposed convolutions back to pixels) next to a local convolution branch, and lets the two exchange features three times. A strided convolutional encoder (``hid_S`` channels, ``N_S`` layers) compresses each frame; TeDev stacks the frames as channels and runs a U-shaped stack of multi-kernel Inception blocks (``N_T`` down, ``N_T`` up, ``hid_T`` channels) with 12 Fourier blocks at its bottleneck; a mirrored decoder returns to pixels, and the output of a complete SimVP network on the raw input is added.

Description
-----------

``earthfarseer`` maps ``T`` input frames ``(batch, T, C, H, W)`` to the next ``T`` frames (Wu et al., AAAI 2024). The spatial block FoTF runs a global Fourier transformer (16x16 patches, 12 blocks of width 768 whose token mixing is an adaptive Fourier neural operator, then three transposed convolutions back to pixels) next to a local convolution branch, and lets the two exchange features three times. A strided convolutional encoder (``hid_S`` channels, ``N_S`` layers) compresses each frame; TeDev stacks the frames as channels and runs a U-shaped stack of multi-kernel Inception blocks (``N_T`` down, ``N_T`` up, ``hid_T`` channels) with 12 Fourier blocks at its bottleneck; a mirrored decoder returns to pixels, and the output of a complete SimVP network on the raw input is added.

The default is the official ``Earthfarseer_model(shape_in=(10, 1, 64, 64))`` (the paper's Moving MNIST setting, 10 -> 10 frames): hid_S 512, hid_T 256, N_S 4, N_T 8, Inception kernels 3/5/7/11 with 8 groups, 157,518,863 parameters. The official code has no license, so the model is written from the paper and permissively licensed parts (OpenSTL's SimVP Inception block, Apache-2.0); parameter names and creation order follow the official code, so its state dicts load with ``strict=True`` and the same seed gives the same weights.

``task="forecasting"`` returns the frame forecast. ``task="segmentation"`` is a PyHazards adaptation for next-step fire masks: a 1x1 convolution (``segmentation_head``) maps the channels of the first predicted frame to ``out_channels`` logits ``(batch, 1, H, W)``; the Earthfarseer parameters keep their official names at the top level of the state dict.

Reproduction
------------

- **Reference implementation:** `https://github.com/Alexander-wu/EarthFarseer <https://github.com/Alexander-wu/EarthFarseer>`__ at ``258d4bb`` (none (no LICENSE file; the README's Apache-2.0 badge links to OpenSTL's licence and does not license this repository); used only as a test oracle, not copied)
- **Checked configuration:** Earthfarseer_model(shape_in=(10, 1, 64, 64)) with its defaults hid_S=512, hid_T=256, N_S=4, N_T=8, incep_ker=[3, 5, 7, 11], groups=8 (timm 0.9.16 as in the official requirements): 157,518,863 parameters, seeded initialisation and outputs compared locally with PYHAZARDS_ORACLE_LARGE=1 (bit-identical in eval and train mode). CI compares three reduced models (other frame counts, channels, sizes, N_S 2/4/6, N_T 2/3, kernels and groups) in which only the hard-coded FoTF transformer width and depth (768, 12) are overridden in the official GF_Block call, plus official state dicts loaded into the builder's forecasting and segmentation models.
- **Parameter count:** 157,518,863
- **Verified:** parameter count, seeded initialisation, parameter names and shapes, forward outputs
- **Oracle test:** ``tests/oracle/test_earthfarseer_oracle.py``
- **Deviation:** task="segmentation" (first predicted frame, 1x1 convolution to out_channels logits) is a PyHazards adaptation, not from Sim2Real-Fire, whose baseline heads are unpublished.
- **Deviation:** The official model sizes the TeDev Fourier token grid as int(H / 2 ** (N_S / 2)), plus 1 when H is divisible by 3. Because H must be a multiple of 16, this disagrees with the real latent size, and the official forward fails, whenever H is divisible by 3 (48, 96, ..., 384) or N_S is odd. PyHazards uses the real latent size, which equals the official value wherever the official model runs.
- **Deviation:** The official FoTF builds its transformer for H x H (img_size=H), so non-square inputs fail its patch-embedding assertion; PyHazards builds it for H x W.
- **Deviation:** gf_embed_dim, gf_depth and num_interactions are hard-coded in the official model (768, 12, 3); PyHazards exposes them only to build smaller models (smoke tests). Their defaults give the official network.

Notes
-----

- The output has as many frames as the input. The paper's temporal projection to other lengths (10 -> 30, 50 -> 50 frames) is not in the released code, so it is not provided.
- Height and width must be multiples of 16 (FoTF patches and its 16x transposed-convolution head) and of the encoder stride; the parameter count depends on the frame count and size (for example 145,121,999 for 3 frames of 1 x 256 x 256).
- Kept from the official code because they change outputs or parameter counts: the same global transformer and local branch are applied seven times inside FoTF; the transformer MLP replaces fc2 by an average pool over groups of four hidden features (fc2 is built but unused); the Fourier operator's second layer computes its imaginary part from the already updated real part; a second encoder (enc) is built but unused; the added SimVP branch (skip_conneciton, spelling kept) has fixed sizes 16 / 256 / 4 / 8.
- Where the paper and the released code differ, PyHazards follows the code: the local branch is one 1x1 transposed convolution (the paper describes 3x3 ConvNormReLU units), the FoTF up-exchange is a transposed convolution and the down-exchange a convolution (the paper states the reverse), and the TeDev kernels are 3/5/7/11 (the paper lists 1/3/7/11).
- Every dropout and stochastic-depth rate is 0 in the official model, so training and evaluation mode give the same outputs (GroupNorm and LayerNorm only).
- No official pretrained weights were found.
