Description
-----------

``logistic_regression`` scores every pixel with a linear function of the ``kernel_size x kernel_size`` window of input features around it, implemented as one ``Conv2d`` with ``kernel_size // 2`` padding; the sigmoid is applied by the loss.

This is exactly the WildfireSpreadTS logistic-regression baseline (``Conv2d(C, 1, kernel_size=3, padding=1)``, 361 parameters for 40 channels). Next Day Wildfire Spread fits the same model on 3x3 neighbourhoods with scikit-learn instead of gradient descent. Multi-day input ``(batch, time, channels, height, width)`` is flattened to ``time * channels`` channels.
