Description
-----------

``unetr`` is UNETR (Hatamizadeh et al., WACV 2022): a 12-layer ViT encodes non-overlapping patches, and the tokens of layers 3, 6, 9 and 12 are reshaped to feature maps, up-sampled by transposed convolutions and merged into a convolutional decoder with residual blocks. The implementation is MONAI's (1.3.2, Apache-2.0; the authors' official code builds on it), ported to plain PyTorch with MONAI's module names, so MONAI state dicts load with ``strict=True``.

With the defaults (``spatial_dims=3``) the model is TS-SatFire's UNETR-3D: input ``(batch, time, channels, H, W)`` built for ``img_size = (history, 256, 256)``, patches of (1, 16, 16) so that tokens never span several days, (1, 2, 2) transposed convolutions, a (1, 3, 3) kernel in ``decoder3``, feature size 16, hidden size 384, MLP 1536, batch norm, and two-class logits averaged over time. ``spatial_dims=2`` gives TS-SatFire's UNETR-2D, which is stock MONAI (patch 16) with the same widths.

Reproduction
------------

- **Reference implementation:** `https://github.com/Project-MONAI/MONAI <https://github.com/Project-MONAI/MONAI>`__ at ``1.3.2`` (Apache-2.0)
- **Checked configuration:** TS-SatFire's UNETR(in_channels=43, out_channels=2, img_size=(T, H, W), spatial_dims=3, norm_name="batch", feature_size=16, patch_size=(1, 16, 16), hidden_size=384, mlp_dim=1536) from spatial_models/unetr/unetr.py at da75732 (MONAI 1.3.2 code with a patch_size argument and hard-coded (1, 2, 2) up-sampling and (1, 3, 3) decoder3 kernel; the repository has no license and is used only as a test oracle), with its outputs averaged over time, built for (T, H, W) = (2, 32, 32) for the forward checks and at (6, 256, 256) on the meta device for the parameter counts (28,816,866 for prediction; 34,806,506 for the 8-channel, feature-size-36 AF/BA configuration); MONAI 1.3.2 UNETR(spatial_dims=2, in_channels=8, feature_size=16, hidden_size=384, mlp_dim=1536, norm_name="batch") for the 2D baseline (23,521,186 parameters at 256x256, forward at 64x64); and 2D/3D MONAI configurations with instance norm, dropout, qkv bias, perceptron patch embedding, plain blocks and attention-matrix saving.
- **Parameter count:** 28,816,866
- **Verified:** parameter count, seeded initialisation, parameter names and shapes, forward outputs
- **Oracle test:** ``tests/oracle/test_unetr_oracle.py``
- **Deviation:** The released TS-SatFire unetr.py has no ``kernel_size_up_down`` argument: it hard-codes (1, 2, 2) for every transposed convolution, while the prediction script passes ``kernel_size_up_down=(1, 2, 2)`` (and reads an undefined ``args.unetr_version``), so the script cannot build UNETR-3D as released. Here ``kernel_size_up_down`` is an argument (MONAI's 2 by default); at (1, 2, 2) it gives the released file's network exactly.
- **Deviation:** Feature size: the paper says 36 was picked for UNETR and SwinUNETR, the prediction script uses 16. The defaults follow the prediction script. Table 3's 34.8M is the AF/BA configuration of the paper text (8 channels, feature size 36, T = 6: 34,806,506 parameters); the prediction configuration has 28,816,866 (38,282,426 with feature size 36).
- **Deviation:** TS-SatFire averages the 3D logits over time in its training script; here that read-out is part of the model (``time_reduction="mean"``), which also takes ``(batch, time, channels, H, W)`` instead of ``(batch, channels, time, H, W)``.
- **Deviation:** The ViT classification head (``classification=True``) is not ported because UNETR never builds it; the deprecated ``pos_embed`` argument is dropped. Inputs must have exactly ``img_size`` (ValueError; the reference fails with a shape error), and configurations whose decoder could not return to the input resolution (patch size not equal to ``kernel_size_up_down ** 4``) raise ValueError up front.

   model = build_model(name="unetr", task="segmentation", in_channels=43, history=4)

Notes
-----

- The position embedding fixes the input size: the model is built for img_size = (history, image_size, image_size) and accepts only that size.
- Each patch-size entry must equal kernel_size_up_down ** 4 (16 = 2 ** 4 in height and width, 1 = 1 ** 4 in time), so the four up-sampling steps return to the input resolution.
- Pass hidden_size=768, mlp_dim=3072 for the prediction script's 'v0' widths or MONAI's defaults (also norm_name='instance').
- time_reduction='none' returns per-date maps (batch, classes, time, H, W).
