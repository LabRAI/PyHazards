Description
-----------

``ts_satfire`` builds one of the next-day wildfire progression baselines of the TS-SatFire dataset, configured as in its prediction script. TS-SatFire is a dataset paper; its prediction baselines are MONAI networks run in 3D over (time, height, width). ``baseline`` selects ``unet3d``, ``attention_unet3d``, ``unetr3d`` or ``swinunetr3d`` (default; the model behind the paper's seed and time-length studies).

Each architecture is also available on its own (``unet3d``, ``attention_unet``, ``unetr``, ``swin_unetr``) with configurable hyperparameters; this entry fixes them to the TS-SatFire values. The input is ``(batch, T, 43, 256, 256)``: 27 VIIRS, weather, forecast, topography and fuel bands with the 17-class land cover one-hot encoded in place, over T in {2, 4, 6} days. The two-class logits are averaged over time to ``(batch, 2, 256, 256)``, as in the script.

Reproduction
------------

- **Reference implementation:** `https://github.com/zhaoyutim/TS-SatFire <https://github.com/zhaoyutim/TS-SatFire>`__ at ``da75732`` (none (no LICENSE file; used only as a test oracle; the networks are ported from MONAI 1.3.2, Apache-2.0))
- **Checked configuration:** run_spatial_temp_model_pred.py with n_channel 43, two classes and T days: UNet and AttentionUnet (spatial_dims=3, channels (64, 128, 256, 512, 1024), strides (1, 2, 2)), UNETR (img_size (T, 256, 256), patch (1, 16, 16), feature size 16, hidden 384, MLP 1536, batch norm) and SwinUNETR (patch (1, 2, 2), window (T, 4, 4), feature size 36 (-ed), 3 heads per stage (-nh), batch norm, attn_version "v1") from the repository's spatial_models, outputs averaged over time. Parameter counts at T = 6, 256x256 (unet3d 31,712,970, attention_unet3d 94,555,506, unetr3d 28,816,866, swinunetr3d 33,191,942; Table 3: 31.7M, 94.5M, 34.8M, 33.2M); names, seeded initialisation and eval / train-mode outputs at T = 2 on 32x32 tiles for CPU speed.
- **Parameter count:** 33,191,942
- **Verified:** parameter count, seeded initialisation, parameter names and shapes, forward outputs
- **Oracle test:** ``tests/oracle/test_ts_satfire_oracle.py``
- **Deviation:** The released prediction script cannot build ``unetr3d``: it reads an undefined ``args.unetr_version`` and passes ``kernel_size_up_down=(1, 2, 2)``, which the released unetr.py does not accept (it hard-codes that value). The preset builds the released file's network with the script's default widths (hidden 384, MLP 1536, as in the paper text); ``unetr_version="v0"`` gives the script's alternative 768 / 3072.
- **Deviation:** UNETR feature size: the script uses 16, the paper text says 36 was picked for UNETR and SwinUNETR; the preset follows the script (``feature_size`` overrides it). Table 3's 34.8M for UNETR-3D is the 8-channel AF/BA configuration with feature size 36 (34,806,506 parameters), not the prediction model (28,816,866; 38,282,426 with feature size 36).
- **Deviation:** SwinUNETR's heads per stage (the script's ``-nh``) are not published; the preset uses 3 (``num_heads``). Any of 3, 4, 6 or 12 gives Table 3's 33.2M.
- **Deviation:** TS-SatFire averages the logits over time in its training loop; here that read-out is part of the model (``time_reduction="mean"``), which also takes ``(batch, T, channels, H, W)`` instead of ``(batch, channels, T, H, W)``.

Notes
-----

- Paper Table 3 (prediction, 6 days; F1 / IoU): U-Net-3D 0.375 / 0.338, Attention-U-Net-3D 0.354 / 0.312, UNETR-3D 0.371 / 0.336, SwinUNETR-3D 0.374 / 0.331. Table 4 (SwinUNETR-3D, seeds 42-44): F1 0.371 +/- 0.003, IoU 0.332 +/- 0.003.
- Paper training for prediction: Dice + weighted cross-entropy (1:1, class weights [1, 446.78]) with learning rate 0.001 and batch 64 (U-Net-3D), 4 (UNETR-3D) or 8 (SwinUNETR-3D); Dice loss, learning rate 0.0012 and batch 8 for Attention-U-Net-3D. The released script uses MONAI's DiceLoss(sigmoid=True) with Adam for all four.
- UNETR-3D and SwinUNETR-3D are built for exactly (history, image_size, image_size); the U-Nets need height and width divisible by 16.
- The two output channels are the not-burning / burning one-hot target of TS-SatFire's FireDataset; the script scores channel 1 after a sigmoid and a 0.5 threshold.
