TropiCycloneNet Dataset
=======================

The TropiCycloneNet Dataset (TCND) of Huang et al. (2025) - best tracks, environmental features and ERA5 500 hPa geopotential for 3,630 storms in six basins - read in the layout of the official TropiCycloneNet loader.

Overview
--------

TCND combines Data1d (best-track position, central pressure and 2-minute maximum wind, normalised), Data3d (ERA5 geopotential, wind and SST around the storm) and Env-Data (intensity class, motion, month, location bins, 12/24-hour motion direction, 24-hour intensity change). It is the training and test data of the TropiCycloneNet model.

``tropicyclonenet_dataset`` builds samples exactly like the official ``TrajectoryDataset`` and ``seq_collate`` (checked by an oracle test): windows of 8 observed and 4 future six-hourly steps, the observed track and its steps, Env-Data per observed step and 64 x 64 scaled 500 hPa geopotential frames; targets are the future latitude, longitude, pressure (hPa) and wind (m/s).

Data Characteristics
--------------------

- Expected layout (the official loader's names under ``root``): ``BST_data/<area>/<train|val|test>/<AREA><YEAR>BST<NAME>.txt``, ``Env_data/<area>/<year>/<NAME>/<YYYYMMDDHH>.npy`` and ``ERA5_gph500/<area>/<year>/<NAME>/<YYYYMMDDHH>.npy``; the Zenodo training-data archives extract to ``bst_divi10_train_val_test_inlcude15_2023``, ``all_area_correct_location_includeunder15_2023`` and ``all_ocean_gph500_2023`` (pass them as ``data1d_dir``, ``env_dir`` and ``gph_dir``).
- Normalisation of Data1d: longitude = 5 x + 180 degrees east, latitude = 5 y, pressure = 50 p + 960 hPa, wind = 25 w + 40 m/s. GPH crops (100 x 100) are resized to 64 x 64 bilinearly and scaled with the range (44490.578125, 58768.4486860389), clipped to [0, 1].
- Env-Data features that are not yet defined (value -1, e.g. the 24-hour history at a track's start) are replaced by the first defined value in the window, as the official loader does. The Env-Data files also contain future-looking keys (future_direction24, future_inte_change24), which are not read.
- The whole requested split is loaded into memory (about 0.13 MB per sample); restrict ``areas``, ``splits`` or ``max_samples`` for large runs. Env-Data files are pickled numpy objects (loaded with allow_pickle); only read files from the official release.

Registry Workflow
~~~~~~~~~~~~~~~~~

Primary dataset name: ``tropicyclonenet_dataset``

.. code-block:: python

   from pyhazards.datasets import load_dataset

   data = load_dataset(
       "tropicyclonenet_dataset",
       data1d_dir="TCND/bst_divi10_train_val_test_inlcude15_2023",
       env_dir="TCND/all_area_correct_location_includeunder15_2023",
       gph_dir="TCND/all_ocean_gph500_2023",
       areas=["WP"],
       splits=["test"],
   ).load()
   test = data.get_split("test")
   print(test.inputs["obs_traj"].shape, test.inputs["image_obs"].shape, test.targets.shape)

- Inputs are a dict: obs_traj / obs_traj_rel (8, N, 4), image_obs (N, 1, 8, 64, 64), env_data (nine arrays (N, 8, width)); targets (N, 4, 4) = lat, lon, pres, wind at 6-24 h.
- root= is accepted when the three folders are named BST_data, Env_data and ERA5_gph500.
