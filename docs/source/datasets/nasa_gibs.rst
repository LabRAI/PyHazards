NASA GIBS
=========

NASA EOSDIS global imagery via WMS/WMTS used for daily true-color satellite imagery.

Overview
--------

In PyHazards it acts as daily wildfire scene imagery context and a lightweight remote-sensing browse layer for event inspection.
