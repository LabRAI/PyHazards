Synthetic TCND Samples
======================

Random inputs in the TropiCycloneNet (TCND) layout with random-walk targets for smoke tests of tropicyclonenet.

Overview
--------

Synthetic data. Every value is a random number; nothing in it describes real tropical cyclones and scores on it mean nothing. It exists so that smoke tests and CI can run the models and the cyclone benchmark without downloading data.

Data Characteristics
--------------------

- obs_traj / obs_traj_rel (8, N, 4) normalised random walks, image_obs (N, 1, 8, 64, 64) uniform, env_data random one-hot features; targets (N, 4, 4) lat, lon, pressure (hPa) and wind (m/s) continuing the walk.

~~~~~~~~~~~~~~~~~

- Smoke tests and CI runs of the linked models and of the cyclone benchmark.
