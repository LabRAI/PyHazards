Synthetic Hurricast Inputs
==========================

Random inputs in the hurricast_ibtracs_era5 layout (8 steps of 30 statistical features and 9 maps of 25 x 25) for smoke tests of hurricast.

Overview
--------

Synthetic data. Every value is a random number; nothing in it describes real tropical cyclones and scores on it mean nothing. It exists so that smoke tests and CI can run hurricast and the cyclone benchmark without IBTrACS or ERA5 files.

Data Characteristics
--------------------

- x_stat (N, 8, 30) with standard-normal numerical features, cyclic encodings in [-1, 1] and valid one-hot basin / nature columns; x_viz (N, 8, 9, 25, 25) standard normal; position (N, 2); targets random winds (kt) or positions (target='displacement').

Typical Use Cases
~~~~~~~~~~~~~~~~~

- Smoke tests and CI runs of hurricast and of the cyclone benchmark.
