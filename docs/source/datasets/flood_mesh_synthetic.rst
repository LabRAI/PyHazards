Synthetic Mesh Hydrographs
==========================

Random mesh fields and toy hydrographs in the HydroGraphNet (White River) layout, for smoke tests of hydrographnet and of mesh inundation rollouts.

Overview
--------

Synthetic data. Static fields are random and the depth series is a toy function of a random inflow curve and the terrain; scores on it mean nothing. It runs the same pipeline as ``hydrographnet_white_river`` (normalisation, 4-nearest-neighbour graph, 16 node features, training windows with physics data, rollout test split), so models and the flood benchmark can be exercised without the 8.3 GB release. ``write_hydrograph_files`` writes such data in the release's file layout.

Data Characteristics
--------------------

- Default: 64 nodes, 4 training and 2 test hydrographs of 48 steps, rollouts of 30 steps; ``micro=True``: 24 nodes, 2 + 1 hydrographs of 16 steps, rollouts of 6 steps.

Typical Use Cases
~~~~~~~~~~~~~~~~~

- Smoke tests and CI runs of hydrographnet and of the ``flood.inundation`` mesh rollouts.
