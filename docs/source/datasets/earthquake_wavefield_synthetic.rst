Synthetic Wavefield Sequences
=============================

Synthetic X / Y / Z ground-velocity wavefields of point sources for wavefield-forecasting smoke runs. Not real data.

Overview
--------

This dataset is synthetic. Each sequence is a point source at a random grid position and onset radiating a P and an S wavefront (Ricker pulses at two speeds, amplitudes decaying with distance): P moves particles radially and vertically, S transversally, giving X, Y and Z velocity channels. It mimics only the layout of WaveCastNet's data (three velocity components on a regular grid); it is not an elastic simulation and says nothing about forecasting skill on real or SW4-simulated wavefields.

It exercises the ``earthquake.forecasting`` task (ACC / RFNE / RMSE of WaveCastNet) in CI. Formerly ``earthquake_forecast_synthetic`` (moving Gaussian blobs; that name is kept as a deprecated alias) and, before that, ``aefa_forecast``: AEFA is an unrelated earthquake-occurrence forecasting dataset.

WaveCastNet's own data (SW4 simulations of the San Francisco Bay Area, arrays ``(events, 3, 376, 256, 461)``, 16-24 GB per file) are on the authors' Google Drive; PyHazards has no reader for them yet.

Data Characteristics
--------------------

- Inputs ``(n, 3, temporal_in, height, width)``, targets ``(n, 3, temporal_out, height, width)``; channels X, Y, Z (``channel_names`` metadata).
- Seeded generator (``seed``); ``vp`` and ``vs`` are wave speeds in grid cells per frame; height and width default to multiples of 8, as WaveCastNet needs.
