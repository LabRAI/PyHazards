Synthetic SHIPS Predictors
==========================

Random inputs in the layout of ships_xu2021 (121 predictors, 24-hour intensity change in knots) for smoke tests of tropicalcyclone_mlp.

Overview
--------

Synthetic data. Every value is a random number; nothing in it describes real tropical cyclones and scores on it mean nothing. It exists so that smoke tests and CI can run the models and the cyclone benchmark without downloading data.

Data Characteristics
--------------------

- (samples, 121) standard-normal inputs; targets are a fixed random linear function of two inputs plus noise, rounded, labelled knots; test years 2017 / 2018 alternate.

Typical Use Cases
~~~~~~~~~~~~~~~~~
