SeisBench-format Waveforms
==========================

Reader for labelled three-component waveform datasets in the SeisBench format (STEAD, INSTANCE, ETHZ, ... as distributed for SeisBench) and in STEAD's own CSV + HDF5 layout.

Overview
--------

``seisbench_waveforms`` reads real phase-picking datasets from disk: the SeisBench format (``metadata.csv`` + ``waveforms.hdf5``, optionally in chunks, with trace blocks ``<block>$<slice>``) and the layout in which the STEAD authors distribute STEAD (``<name>.csv`` + ``<name>.hdf5``, one ``(6000, 3)`` E/N/Z array per trace). PyHazards implements the reader itself with ``h5py`` and ``csv``; SeisBench (GPL-3.0) is not imported. Its output equals SeisBench's ``WaveformDataset`` on a dataset written by SeisBench's ``WaveformDataWriter`` (``tests/oracle/test_seisbench_reader_oracle.py``).

Nothing is downloaded or redistributed: STEAD is about 85 GB and INSTANCE's event waveforms about 160 GB. Download them from their providers (or with SeisBench, which converts them to its format) and pass the directory as ``path``.

Data Characteristics
--------------------

- Inputs ``(n, 3, window)`` float32 in the dataset's component order (``metadata["component_order"]``, e.g. ``ZNE`` for SeisBench files, ``ENZ`` for STEAD's own files); the earthquake benchmark reorders channels to each model's order. Targets ``(n, 2)``: P and S arrival samples relative to the window start, NaN when a trace has no such arrival (noise traces) or it falls outside the window.
- Splits follow the dataset's ``split`` column (``train`` / ``dev`` -> ``val`` / ``test``). STEAD's own files have no split: ``test_trace_names`` (e.g. EQTransformer's ``ModelsAndSampleData/test.npy``) selects the test traces and the rest are ``train``; without it all traces are ``test``.
- Arrival columns are read in order of preference (``trace_p_arrival_sample``, ``trace_P_arrival_sample``, ``trace_P1_arrival_sample``, ``trace_Pg_arrival_sample``, ... and the S equivalents; ``p_arrival_sample`` / ``s_arrival_sample`` for STEAD files); ``phase_columns`` overrides the list.
- Licences: STEAD and INSTANCE are CC BY 4.0 (STEAD repository LICENSE; INGV INSTANCE page and repository). Cite the dataset papers below when publishing results.

Typical Use Cases
~~~~~~~~~~~~~~~~~

- Scoring PhaseNet, EQTransformer and GPD (official weights) with the ``earthquake.picking`` benchmark.
- Training phase pickers on real labelled waveforms.

PyHazards Usage
---------------

Pair it with ``phasenet``, ``eqtransformer`` (60-s windows, ``window_samples=6000``) or ``gpd`` and the ``earthquake`` benchmark (``hazard_task=earthquake.picking``).

Registry Workflow
~~~~~~~~~~~~~~~~~

Primary dataset name: ``seisbench_waveforms``

.. code-block:: python

   from pyhazards.datasets import load_dataset

   # A SeisBench-format directory (metadata.csv + waveforms.hdf5), e.g. SeisBench's copy of STEAD.
   data = load_dataset("seisbench_waveforms", path="~/.seisbench/datasets/stead", max_traces=1000).load()

   # STEAD as distributed by its authors (merged.csv + merged.hdf5) with EQTransformer's test split.
   stead = load_dataset(
       "seisbench_waveforms",
       path="/data/STEAD",
       preset="stead",
       test_trace_names="/data/STEAD/test.npy",
   ).load()
   test = stead.get_split("test")
   print(test.inputs.shape, test.targets.shape)  # (n, 3, 6000), (n, 2)

- ``window_samples`` / ``window_start`` cut a fixed window (zero-padded when a trace is shorter); traces of different lengths need it.
- ``max_traces`` keeps the first rows of each split (``micro=True`` keeps 8); ``trace_category`` filters STEAD's ``earthquake_local`` / ``noise`` rows.
- ``preset='instance'`` supplies INSTANCE's component order (E, N, Z) and 100 Hz when the files lack a ``data_format`` group.
