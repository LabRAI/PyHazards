Synthetic Urban Flood Events
============================

Random urban flood events in the UrbanFloodCast one-shot layout (current state, rainfall and terrain in; depth and discharges of 24 steps out), for smoke tests of urbanfloodcast.

Overview
--------

Synthetic data. Each event is a random rain pulse on a tilted random terrain with NaN "buildings"; scores on it mean nothing. The events go through ``prepare_urbanfloodcast_event``, the official UrbanFloodCast one-shot preparation (checked against the official ``flood_data``), so the inputs ``(n, Sy, Sx, 24, 1, 5)``, targets ``(n, Sy, Sx, 24, 3)`` and NaN mask have the layout of the real benchmark. PyHazards has no reader for the Berlin GeoTIFFs yet (Zenodo 10.5281/zenodo.15700880).

Data Characteristics
--------------------

- Inputs per cell and step: depth, x / y unit discharge at the start (repeated), log(1 + rain / 0.01) / 10, terrain L2-normalised along x; targets: depth, x / y unit discharge; the mask is in ``split.metadata['mask']``.

Typical Use Cases
~~~~~~~~~~~~~~~~~

- Smoke tests and CI runs of urbanfloodcast and of the ``flood.inundation`` raster evaluation.
