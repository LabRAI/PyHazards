Synthetic Storm Histories
=========================

Random storm-history features and lat / lon / intensity targets for smoke tests of the generic experimental storm adapters (hurricast, tcif_fusion, graphcast_tc, pangu_tc, fourcastnet_tc).

Overview
--------

Synthetic data. Every value is a random number; nothing in it describes real tropical cyclones and scores on it mean nothing. It exists so that smoke tests and CI can run the models and the cyclone benchmark without downloading data.

Data Characteristics
--------------------

- (samples, history=6, features=8) standard-normal inputs; targets (samples, horizon=5, 3) are the last step's first three features plus a fixed drift, labelled lat, lon and wind with lead times 6-30 h.

Typical Use Cases
~~~~~~~~~~~~~~~~~

- Smoke tests and CI runs of the linked models and of the cyclone benchmark.
