Synthetic Wavefield Sequences
=============================

Synthetic dense-grid wavefield sequences for wavefield-forecasting smoke runs. Not real data.

Overview
--------

This dataset is synthetic: moving Gaussian blobs over sinusoidal backgrounds on a small grid, split into history and future frames. It only exercises the ``earthquake.forecasting`` path (``wavecastnet``) in CI. It used to be registered a second time as ``aefa_forecast``; AEFA is an unrelated earthquake-occurrence forecasting dataset, so that name was removed.
