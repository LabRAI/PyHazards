CAMELS-US
=========

Overview
--------

``camels_us_streamflow`` reads a local CAMELS-US copy with the paper's defaults (forcings, the 27 attributes, 270-day windows, train 1999-10-01 to 2008-09-30, test 1989-10-01 to 1999-09-30). The ``flood.streamflow`` evaluator reports the median and mean NSE over basins and the number of basins with NSE <= 0, as in Table 2 of the paper, plus KGE, alpha-NSE, beta-NSE, FHV, FMS and FLV.

Applied to the official stored simulations of the 2019 runs, the PyHazards metrics give the paper's Table 2 values (e.g. EA-LSTM NSE* median 0.71 single / 0.74 ensemble; LSTM with static inputs 0.73 / 0.76). The smoke configs exercise the contract on synthetic basins.
