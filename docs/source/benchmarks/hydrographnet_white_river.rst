HydroGraphNet White River
=========================

Overview
--------

``hydrographnet_white_river`` reads a local copy of the release exactly like PhysicsNeMo's ``HydroGraphDataset``. The ``flood.inundation`` evaluator rolls every test hydrograph out for 30 steps (10 hours) with the model's ``rollout`` method, as the HydroGraphNet example's inference script does, and reports ``rollout_rmse`` (depth RMSE per step, averaged over steps and hydrographs, in metres; the per-step curve is in the report metadata), depth MAE / RMSE, CSI and NSE.

The release has no official test split, and the paper's numbers could not be accessed, so no paper result is reproduced. The smoke config runs the contract on ``flood_mesh_synthetic``.
